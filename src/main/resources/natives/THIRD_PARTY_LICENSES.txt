Third-party code in the 3D Futura Engine native library (natives/*/libfutura3d.so, futura3d.dll)
==============================================================================================

Built from native/ in the 3D Futura Engine repository with native/build.sh (Zig toolchain, statically linked).

1. YesSteveModel-Native, https://github.com/YesSteveModel/YesSteveModel-Native, branch dev, commit
   907d1c653b7eb85ee92ee11305134408300797f8. Apache License 2.0 (the LICENSE file of the mod; native/upstream/LICENSE).
   The legacy v3 decoder (modules/legacy/src/v3/codec, modules/legacy/src/v3/container) and parts of modules/core/src.
   Within it:
   - the 64-bit part of the historical YSM fork of CityHash 1.1.1, Copyright (c) 2011 Google, Inc., MIT license
     (text below);
   - ChaCha/HChaCha after the floodyberry reference implementation (public domain or MIT) and SIMD block layouts
     adapted from Crypto++ 8.9 chacha_simd.cpp / chacha_avx.cpp (placed in the public domain by Jack Lloyd and
     Jeffrey Walton).
2. Abseil, https://github.com/abseil/abseil-cpp, tag 20240722.0. Apache License 2.0.
3. Zstandard, https://github.com/facebook/zstd, v1.5.7. BSD license (text below).
4. libwebp, https://github.com/webmproject/libwebp, v1.4.0 (decoder). BSD license (text below).
5. The C++ runtime linked by Zig: LLVM libc++, libc++abi and libunwind (Apache License 2.0 with LLVM Exceptions);
   on Windows the mingw-w64 runtime (see https://www.mingw-w64.org; public domain and permissive licenses).
